How this demo is wired

This page intentionally loads the supplied engine as a sibling file: <script src="./rakitrakatra.js"></script>. The engine exports the runtime on R, R4 and Rakitrakatra, so each demo uses the same engine rather than duplicating plugin logic. The plugin manager in the engine also supports registry, global install, scene install and updates.
